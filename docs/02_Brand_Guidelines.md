# Brand Guidelines

> A identidade da marca Indexa.

---

# Essência da Marca

O Indexa nasceu para organizar aquilo que acompanha as pessoas durante toda a vida: suas histórias.

Livros, filmes, séries, animes e jogos fazem parte da memória afetiva de cada pessoa.

O papel do Indexa é preservar essa jornada de forma elegante, organizada e intuitiva.

---

# Propósito

Ajudar pessoas a organizar sua biblioteca de entretenimento em um único lugar.

---

# Posicionamento

O Indexa não compete com plataformas como Letterboxd, MyAnimeList ou Goodreads.

Ele complementa essas plataformas, reunindo diferentes mídias em uma biblioteca pessoal única.

---

# Personalidade

Se o Indexa fosse uma pessoa, seria alguém:

• Organizado

• Inteligente

• Calmo

• Discreto

• Elegante

• Prestativo

Nunca seria:

• Infantil

• Chamativo

• Barulhento

• Exagerado

• Competitivo

---

# Arquétipo

Principal

Sábio (The Sage)

O Indexa organiza conhecimento.

Valoriza informação.

Ajuda o usuário a encontrar rapidamente aquilo que procura.

---

Secundário

Cuidador (The Caregiver)

Protege a biblioteca do usuário.

Preserva memórias.

Registra sua jornada.

---

# Slogan

# Missão

# Valores

Simplicidade

---

# Tom de voz

O Indexa conversa como um bom bibliotecário.

Educado.

Objetivo.

Prestativo.

Nunca informal em excesso.

Nunca robótico.

---

Exemplos

✔ Obra adicionada.

✔ Biblioteca atualizada.

✔ Episódio concluído.

✔ Nenhuma obra encontrada.

✔ Você concluiu esta coleção.

Evitar

❌ Sucesso!!!

❌ Parabéns!!

❌ Uhuuu!!

❌ Incrível!!

❌ Sensacional!!

---

# Escrita

Sempre utilizar frases curtas.

Evitar textos longos.

Botões sempre começam com verbos.

Exemplos

Salvar

Editar

Cancelar

Excluir

Importar

Exportar

# Emojis

O uso de emojis deve ser mínimo.

Utilizar apenas quando agregarem significado.

Exemplos permitidos

❤️ Favorito

⭐ Avaliação

📚 Biblioteca

🎬 Filmes

📖 Livros

🎮 Jogos

Evitar emojis decorativos.

---

# Ícones

Preferência por Material Symbols Rounded.

Todos devem possuir:

- mesmo peso
- mesmo tamanho
- mesmo estilo

Misturar famílias de ícones não é permitido.

---

# Identidade Visual

O design deve transmitir:

leveza

organização

espaço

clareza

Nunca transmitir:

poluição

caos

interface técnica

visual infantil

---

# Princípios Visuais

Muito espaço em branco.

Poucos elementos.

Hierarquia evidente.

Informação agrupada.

Consistência.

---

# Cores

A paleta oficial encontra-se documentada no Design System.

A marca utiliza cores apenas para orientar.

Nunca para decorar.

---

# Tipografia

A tipografia oficial encontra-se documentada no Design System.

Priorizar excelente legibilidade.

Evitar excesso de Bold.

---

# Linguagem Visual

O conteúdo sempre é o protagonista.

A interface deve desaparecer.

O usuário deve enxergar primeiro:

1. A capa

2. O título

3. O progresso

4. O status

Todo o restante é secundário.

---

# Experiência

O usuário nunca deve sentir que está preenchendo um formulário.

Ele deve sentir que está organizando sua biblioteca.

---

# O que queremos transmitir

Quando alguém abrir o Indexa deve pensar:

"Está tudo organizado."

Não:

"Tem muita informação."

---

# Resumo

O Indexa é uma biblioteca pessoal moderna.

Elegante.

Minimalista.

Organizada.

Confiável.

Discreta.

Toda decisão visual deve reforçar essa identidade.
