# User Experience

> A experiência que o Indexa deseja proporcionar.

O Indexa não é apenas um catálogo.

Ele é a memória do entretenimento de uma pessoa.

Toda decisão de design deve preservar essa ideia.

---

# Nossa Missão

Ajudar o usuário a lembrar das histórias que fizeram parte da sua vida.

O Indexa não organiza arquivos.

Organiza lembranças.

---

# A primeira impressão

Ao abrir o aplicativo pela primeira vez, o usuário deve pensar:

"Finalmente encontrei um lugar para organizar tudo."

Nunca:

"Por onde eu começo?"

---

# Sensação durante o uso

O aplicativo deve transmitir:

• calma

• organização

• leveza

• confiança

Nunca deve transmitir:

• ansiedade

• excesso de informação

• pressa

• complexidade

---

# A sensação ao adicionar uma obra

Adicionar uma nova obra deve levar poucos segundos.

O usuário nunca deve sentir que está preenchendo um formulário.

Ele apenas registra algo que passou a fazer parte da sua biblioteca.

---

# A sensação ao concluir uma obra

Concluir uma obra é um momento importante.

O sistema deve reconhecer isso de forma discreta.

Exemplo:

"Obra concluída."

Sem animações exageradas.

Sem confetes.

Sem pop-ups invasivos.

---

# A sensação ao voltar depois de semanas

Ao abrir novamente o Indexa, o usuário deve lembrar imediatamente onde parou.

Por isso a Home sempre prioriza:

• continuar consumindo

• retomar a jornada

Nunca estatísticas.

---

# Biblioteca

A biblioteca deve transmitir a sensação de uma estante organizada.

Tudo deve possuir um lugar.

Nada deve parecer perdido.

---

# Descoberta

Encontrar uma obra deve ser prazeroso.

A busca deve ser rápida.

Os filtros devem ser simples.

O usuário nunca deve precisar pensar em como encontrar algo.

---

# Jornada

O progresso da obra é parte da memória.

O usuário deve conseguir lembrar facilmente:

Onde parou.

Quando começou.

Quando terminou.

Quanto tempo dedicou.

---

# Coleções

Criar uma coleção deve lembrar organizar livros em uma estante.

As coleções representam afinidade.

Não apenas agrupamentos.

---

# Favoritos

Favoritos representam obras importantes.

Não apenas boas avaliações.

---

# Avaliação

A nota representa a percepção do usuário naquele momento.

Ela pode mudar.

O sistema nunca deve tratar avaliações como definitivas.

---

# Minha opinião

A opinião pessoal é um diário.

Não uma crítica pública.

Ela existe para que o usuário possa revisitar seus próprios pensamentos anos depois.

---

# Linha do tempo

A linha do tempo existe para contar uma história.

Não apenas mostrar datas.

Cada obra adicionada representa um momento da vida.

---

# Dashboard

O Dashboard deve despertar curiosidade.

Nunca competição.

As estatísticas existem para revelar padrões.

Não para gerar metas.

---

# Interface

A interface nunca deve chamar mais atenção do que as capas das obras.

As histórias sempre são protagonistas.

---

# Design Emocional

O usuário deve sentir que:

Sua coleção está segura.

Seu histórico está preservado.

Sua jornada tem valor.

---

# Longo prazo

O verdadeiro valor do Indexa aparece depois de anos.

Quando o usuário voltar a uma obra antiga, ele poderá lembrar:

O que achou.

Onde estava.

Como se sentia.

Esse é o verdadeiro propósito do aplicativo.

---

# A regra mais importante

O usuário não está organizando mídias.

Ele está organizando parte da sua vida.

Toda funcionalidade deve respeitar essa ideia.
