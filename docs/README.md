# Indexa

Sua biblioteca.
Sua jornada.

---

## O que é?

Indexa é uma biblioteca digital para organizar filmes, séries, animes, livros, mangás, HQs e jogos.

Mais do que um catálogo, o Indexa registra sua jornada no entretenimento.

---

## Missão

Ajudar pessoas a preservar suas memórias através das histórias que consumiram.
