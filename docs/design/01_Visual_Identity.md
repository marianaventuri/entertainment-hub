# Visual Identity

> A identidade visual oficial do Indexa.

---

# Nossa personalidade

O Indexa é:

• organizado

• elegante

• discreto

• inteligente

• acolhedor

Nunca deve parecer:

• infantil

• exagerado

• tecnológico demais

• corporativo

• chamativo

---

# Sensação

Ao abrir o aplicativo, o usuário deve sentir:

"Está tudo no lugar."

Essa sensação deve existir em todas as telas.

---

# Inspirações

Nossa linguagem visual é inspirada em:

• Apple Books

• Notion

• Linear

• Arc Browser

• Spotify (organização de biblioteca)

Não copiamos interfaces.

Copiamos princípios.

---

# Estilo

Minimalista.

Muito espaço em branco.

Pouco texto.

Poucas cores.

Hierarquia extremamente clara.

---

# Filosofia

As obras são as protagonistas.

A interface apenas organiza.

---

# Cores

Poucas.

Consistentes.

Nunca usar cor apenas como decoração.

Toda cor comunica algo.

---

# Tipografia

Poucos pesos.

Excelente legibilidade.

Nunca exagerar no Bold.

O conteúdo deve ser confortável para leitura longa.

---

# Ícones

Simples.

Mesmo estilo.

Mesmo peso.

Nunca misturar estilos.

---

# Emojis

Não fazem parte da identidade visual.

Podem aparecer apenas em casos específicos.

Exemplos:

Conquistas.

Mensagens comemorativas.

Estados vazios.

Nunca utilizar emojis para estruturar a interface.

---

# Bordas

Arredondadas.

Suaves.

Sem exagero.

---

# Sombras

Muito discretas.

A profundidade vem do contraste.

Não da sombra.

---

# Espaçamento

Respiração é prioridade.

Uma tela nunca deve parecer apertada.

---

# Movimento

Animações curtas.

Naturais.

Sem exageros.

---

# Impressão final

O usuário deve pensar:

"Esse aplicativo é agradável de usar."
