01 — Essência

A identidade da marca Indexa

O Indexa nasceu para organizar aquilo que acompanha as pessoas durante toda a vida: suas histórias. Livros, filmes, séries, animes e jogos fazem parte da memória afetiva de cada pessoa.

Missão
Organizar a jornada de entretenimento das pessoas de forma simples, elegante e intuitiva.
Visão
Ser a principal biblioteca pessoal de entretenimento.
Promessa
Toda sua biblioteca. Em um único lugar.
Slogan
Sua biblioteca. Sua jornada.
Posicionamento
O Indexa não compete com plataformas como Letterboxd, MyAnimeList ou Goodreads. Ele complementa essas plataformas, reunindo diferentes mídias em uma biblioteca pessoal única.

11 — Princípios

As regras que guiam cada decisão

Toda funcionalidade nova deve fortalecer pelo menos um destes princípios. Se violar algum, deve ser revista.

01
O conteúdo é o protagonista
O usuário deve enxergar primeiro a capa, o título e o progresso. Nunca a interface.
02
Organização acima de quantidade
Adicionar mais funcionalidades não torna o produto melhor. Uma funcionalidade só existe se realmente melhorar a organização.
03
Simplicidade vence complexidade
Sempre escolher a solução mais simples. Se duas soluções resolverem o mesmo problema, utilizar a que exige menos aprendizado.
04
Cada tela possui apenas um objetivo
Home → Retomar jornada. Biblioteca → Encontrar obras. Dashboard → Descobrir padrões. Nunca misturar objetivos.
05
O usuário nunca deve preencher o que a API conhece
Título, ano, autor, sinopse, gêneros, capa — tudo preenchido automaticamente. O usuário apenas complementa informações pessoais.
06
Ações frequentes devem exigir um clique
Favoritar, alterar status, avaliar e continuar progresso nunca devem ficar escondidos.
07
A interface deve desaparecer
Quanto menos o usuário pensar sobre a interface, melhor. O Indexa existe para organizar histórias, não interfaces.
